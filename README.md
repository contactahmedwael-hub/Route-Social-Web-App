# Route Posts

A social web app built on the [Route Posts API](https://route-posts.routemisr.com): share posts, follow people, comment, and keep up with notifications.

## Features

- Sign up, log in, and a session that lasts for the tab
- Feed, My Posts, Community, and Saved pages
- Create, edit, delete, like, share, and bookmark posts, with image upload and an emoji picker
- Comments and replies, with links to each author's profile
- Notifications with All/Unread tabs and read state that survives a refresh
- Profile with photo and cover upload, plus other users' profiles
- Follow suggestions and a search across all users
- Page-specific browser tab titles

## Tech Stack

React 19, TypeScript, Vite, Tailwind CSS v4, React Router, Axios, React Hook Form, React Icons
